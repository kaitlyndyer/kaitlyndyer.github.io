Linear systems & rref Test 1

  • Row ops: swap rows, scale a row by k ≠ 0, add a multiple of one row to another.
  • rref: each pivot is a 1, zeros above and below it, pivots step right, zero rows at the bottom.
  • Free variables = non-pivot columns. x = particular + s(…) + t(…).
  • Inconsistent ⇔ a row [0 … 0 | 1]. Consistent: no free vars ⇒ 1 solution; free vars ⇒ ∞.
  • A is n×m: rank ≤ n and ≤ m. rank = n ⇒ Ax = b always consistent. rank = m ⇒ at most one solution.
  • Square A: unique solution for every b ⇔ rank = n. Ax = b inconsistent for some b ⇔ rank < n.
  • Parameters (h, k): row reduce, find where a pivot becomes 0, test each such value separately.

Matrix algebra Test 1

  • (n×p)(p×m) = n×m. Entry (i, j) of AB = row i of A · column j of B.
  • Ax = x₁(col 1) + … + x_m(col m): Ax is a linear combination of the columns.
  • AB ≠ BA in general. Commute: write B = [[a, b], [c, d]], set AB = BA, solve.
  • AB = 0 does not force A = 0 or B = 0. But A invertible and AC = 0 ⇒ C = 0.
  • v, w solve Ax = b ⇒ v − w solves Ax = 0. All solutions = one solution + ker A.
  • A(x + y) = Ax + Ay, A(kx) = kAx, (AB)C = A(BC), A(B + C) = AB + AC.

Linear transformations Test 1

  • T is linear ⇔ T(x + y) = T(x) + T(y) and T(kx) = kT(x) ⇔ T(x) = Ax.
  • Not linear if T(0) ≠ 0, or any constant, x², xy, |x| appears.
  • A = [T(e₁) … T(e_m)]. T: ℝm → ℝn ⇒ A is n×m.
  • Given T(vᵢ) = wᵢ: write x as a combination of the vᵢ, or A[v₁ … v_m] = [w₁ … w_m] ⇒ A = [w₁ … w_m][v₁ … v_m]−1.
  • “T, then S” = BA (B for S, A for T): the first map goes on the right.

Geometry in ℝ² Test 1

  • Rotate θ counterclockwise: [[cos θ, −sin θ], [sin θ, cos θ]]. Clockwise θ: [[cos θ, sin θ], [−sin θ, cos θ]].
  • 90° CCW: [[0, −1], [1, 0]]. 180°: −I. 45°: cos = sin = 1/√2.
  • Scale by k: kI. Rotation-scaling: [[a, −b], [b, a]].
  • Shear: [[1, k], [0, 1]] (horizontal), [[1, 0], [k, 1]] (vertical).
  • Project onto line through w: P = 1/(w₁² + w₂²) [[w₁², w₁w₂], [w₁w₂, w₂²]]. Not invertible.
  • Reflect in that line: 2P − I = [[a, b], [b, −a]] with a² + b² = 1. Own inverse.
  • Reflect in x-axis [[1, 0], [0, −1]], y-axis [[−1, 0], [0, 1]], y = x [[0, 1], [1, 0]], y = −x [[0, −1], [−1, 0]].
  • ℝ³: reflect in xy-plane diag(1, 1, −1); project onto yz-plane diag(0, 1, 1).

Image & kernel (A is n×m)

  • ker A = {x : Ax = 0} ⊆ ℝm (# columns). im A = span(columns) ⊆ ℝn (# rows).
  • Kernel basis: rref, free vars s, t, …; x = s(…) + t(…).
  • Image basis: pivot columns of A (not rref!).
  • Non-pivot col of rref = coefficients on the pivot cols of A.
  • b ∈ im A ⇔ [A | b] consistent. Rows of zeros in [A | y] give im A = ker B.
  • ker B ⊆ ker AB; im AB ⊆ im A. A² = 0 ⇔ im A ⊆ ker A ⇒ rank ≤ n/2.

Rank–nullity

  • dim ker A + dim im A = m (# columns).
  • rank = # pivots = dim im ≤ min(n, m).
  • ker A = {0} ⇔ rank = m. im A = ℝn ⇔ rank = n.
  • A = BC with B n×k, C k×n, k < n ⇒ ker C ≠ {0} ⇒ A not invertible.

Subspace test

  • (1) 0 ∈ W (2) u + v ∈ W (3) kv ∈ W.
  • Equations = 0 → ker, rows = coefficients. Parameters → im, columns = vectors multiplying each parameter.
  • Not: specific counterexample. Red flags: constants, x², xy, ≥, a ≥ 0.
  • V ∩ W always a subspace; V ∪ W usually not.

Independence, span, basis

  • Independent ⇔ only trivial relation ⇔ ker[v₁ … v_m] = {0} ⇔ rank = m.
  • > n vectors in ℝn ⇒ dependent. Nonzero ⊥ vectors ⇒ independent.
  • Kernel vector (c₁, …, c_m) ⇔ relation c₁v₁ + … + c_m v_m = 0.
  • Basis = spans + independent ⇔ unique representation.
  • dim V = m: m independent vectors in V ⇒ basis; m spanning ⇒ basis.
  • v₁…vₙ basis of ℝn ⇔ [v₁ … vₙ] invertible.
  • Extend: rref[v₁ … v_p | e₁ … eₙ], keep pivot cols.
  • dim(V + W) = dim V + dim W − dim(V ∩ W).

Inverses Test 1

  • [[a, b], [c, d]]−1 = 1/(ad − bc) [[d, −b], [−c, a]]; invertible ⇔ ad − bc ≠ 0.
  • Any size: rref[A | I] = [I | A−1]. Left side not I ⇒ not invertible.
  • Ax = b ⇒ x = A−1b. Check: AA−1 = I.
  • (AB)−1 = B−1A−1 (order flips). (Ak)−1 = (A−1)k. A, B invertible ⇒ AB, Ak invertible.
  • Square: AB = I ⇒ BA = I and B = A−1. rank(AB…) = n ⇒ every factor invertible.
  • Inverse of rotation by θ = rotation by −θ. Reflection = its own inverse. Projections aren’t invertible.
  • Is A − kI invertible? Compute it, then row reduce (or 2×2: check ad − bc).
  • Invertible n×n A ⇔ rref A = Iₙ ⇔ rank n ⇔ ker A = {0} ⇔ im A = ℝn ⇔ cols independent ⇔ cols span ⇔ cols a basis ⇔ Ax = b has a unique solution ∀b.

Orthogonal complement

  • V⊥ = {x : x · v = 0 ∀v ∈ V} = ker(matrix with rows = spanning set of V).
  • dim V + dim V⊥ = n; V ∩ V⊥ = {0}; (V⊥)⊥ = V.
  • Basis V + basis V⊥ = basis of ℝn.
  • V = ker(rows = basis of V⊥).
  • V ∩ W = {0} does NOT imply W = V⊥.

Orthonormal & projections

  • ‖v‖ = √(v·v). Orthonormal: uᵢ·uⱼ = 0, uᵢ·uᵢ = 1. u = v/‖v‖.
  • projVx = (u₁·x)u₁ + … + (u_m·x)u_m (orthonormal basis!).
  • Orthogonal basis: Σ (vᵢ·x)/(vᵢ·vᵢ) vᵢ.
  • x⊥ = x − x∥ ∈ V⊥: check x⊥·vᵢ = 0.
  • P = u₁u₁ᵀ + … + u_m u_mᵀ; im P = V, ker P = V⊥, P² = P.
  • Line: proj = (x·w)/(w·w) w; ref = 2 proj − x.

Coordinates

  • [x]B = (c₁, …, c_m) ⇔ x = c₁v₁ + … + c_m v_m.
  • x = S[x]B, S = [v₁ … v_m]. ℝⁿ basis: [x]B = S−1x.
  • Subspace basis: row reduce [S | x]; inconsistent ⇒ x ∉ V.
  • [x]B has m = dim V entries.

B-matrix

  • [T(x)]B = B[x]B.
  • B = S−1AS, AS = SB, A = SBS−1.
  • Column j of B = [T(vⱼ)]B (coordinates, not T(vⱼ)).
  • Diagonal ⇔ T(vⱼ) = cⱼvⱼ. Proj onto L: diag(1, 0). Reflect: diag(1, −1). Proj onto plane in ℝ³: diag(1, 1, 0).

Similar matrices

  • A ∼ B ⇔ AS = SB, S invertible.
  • Show ∼: S = [[a, b], [c, d]], solve AS = SB, pick det S ≠ 0.
  • Show ≁: different rank / nullity / invertibility; kI ∼ only kI.
  • Equivalence relation. A ∼ B ⇒ Aᵗ ∼ Bᵗ, A + kI ∼ B + kI.
